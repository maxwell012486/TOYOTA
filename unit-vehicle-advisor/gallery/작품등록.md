## 프로젝트명
부대 차량 구매 도우미

## 배포 주소
https://car-decision-helper-eight.vercel.app/unit-vehicle-advisor

## 한 줄 소개
용도·예산·면허·운행 환경만 넣으면 국산 차량 순위와 선정 사유·제한사항을 보고용 PDF로 정리

## 어떤 문제를 해결하나요?
부대 차량 구매 결정권자는 지휘관 업무용 승용차, 인원 수송 승합차, 1톤 화물차, 대형 트럭을 용도에 맞게 골라야 합니다. 그런데 예산, 친환경(충전 인프라·혹한지·험로), 중고/신차, 자동/수동 변속기와 운전 인원의 면허 종류(자동 한정 면허 등), 유지비, 승차 인원·적재량처럼 판단 기준이 6개 이상이고 서로 부딪힙니다. 정보도 조달청 쇼핑몰, 전년도 구매 사례, 일괄 보급 계획으로 흩어져 있어 상급부대에 보고할 때마다 순위와 근거를 수작업으로 정리해 왔습니다. 이 도구는 부대 조건을 기준으로 하나의 순위, 선정 사유, 제한사항과 대책을 자동으로 만들고 그대로 보고서로 출력하게 해 줍니다.

## 주요 기능
① 부대 프로필: 예산, 면허 종류별 운전 인원(누적 막대), 운행 환경, 충전 인프라, 연간 주행거리를 한 번 입력하면 자동 저장
② 용도 카드 5종(승용·승합·1톤 화물·대형 트럭·기타): 고르면 해당 용도의 국산 후보 차량(쏘나타, 스타리아, 포터 II, 마이티 등 37종 제원)이 나오고 조달청 가격만 입력, 중고 후보도 추가
③ 평가 엔진: 용도 적합성 30·예산 25·유지비 20·친환경 15·운전 편의 10 가중치(조정 가능)로 100점 만점 순위, 면허 부적합 −15점·충전 인프라 부족 −5점 감점
④ 상태 태그와 근거: 초록(예산 이내·면허 적합)·노랑(충전기 필요·혹한지 전기차·험로 2WD)·빨강(면허 부적합·예산 초과) 태그, 1순위 선정 사유 3줄, 차량별 제한사항과 대책 문구 자동 생성
⑤ 보고서: A4 세로 보고 양식 PDF 저장, 한글 문서에 붙여 넣는 개조식(1. / 가. / 1)) 문안 복사
⑥ 기록 관리: 전년도 구매 사례·일괄 보급 계획(참고 패널), 평가 이력, 차량 DB·면허 규칙·에너지 단가 편집, JSON 내보내기·가져오기(덮어쓰기/병합)로 부대 간 공유

## 현장 활용 시나리오
내년도 차량 구매 계획을 세우는 날, 부대 인터넷 PC에서 HTML 파일을 더블클릭해 엽니다. 부대 프로필에는 지난번 입력한 예산과 운전 인원 면허 현황이 남아 있습니다. 구매 조건에서 '1톤 화물' 카드를 고르고 필요 적재량 1톤, 구매 대수 2대를 넣은 뒤 포터 II, 봉고 III 후보에 조달청 가격을 입력하면 바로 순위가 나옵니다. 운전 인원 대부분이 자동 한정 면허라면 수동 트림에 빨강 '면허 부적합' 태그와 '자동변속기 트림 선택 또는 면허 취득 교육 계획 반영' 대책이 붙고, 충전기가 없으면 전기 트럭에 '충전기 설치 소요 반영'이 표시됩니다. 보고서 화면에서 PDF로 저장해 상급부대에 올리고, 개조식 문안을 복사해 한글 보고서에 붙입니다. 차량 DB와 전년도 사례는 JSON 파일로 다른 부대에 그대로 나눠 쓸 수 있습니다.

## 사용한 도구·기술
Claude Code(Opus 5.5), HTML·CSS·Vanilla JS 단일 파일, 인라인 SVG 일러스트·차트, localStorage, 브라우저 인쇄(PDF), GitHub, Vercel(공개 데모). 외부 라이브러리·CDN·서버·AI API 없이 오프라인 동작

## 제작 후기 · 어려웠던 점
이번에도 PRD(요구사항 문서)를 먼저 꼼꼼히 쓰고 그대로 개발을 맡겼습니다. PRD에 검증용 테스트 케이스(면허 부적합 −15점, 예산 5% 초과 시 예산 점수 5점 등)를 미리 적어 두었더니 결과가 맞는지 숫자로 바로 확인할 수 있었습니다. 부대 PC 환경을 고려해 인터넷이 막혀도 돌아가도록 외부 라이브러리 없이 파일 하나로 만들고, 비밀 정보 입력 금지 안내와 외부 전송 없는 구조를 기본으로 했습니다. 어려웠던 점은 차종별 제원(연비·적재중량·변속기 조합)과 면허 규칙(1종 보통 자동 한정 면허)을 정확히 맞추는 일이었습니다. 그래서 값을 고정하지 않고 화면에서 직접 고치고 JSON으로 최신 DB를 나눠 쓰도록 했습니다. 실제 구매 검토 때 공식 제원표와 오피넷 단가로 한 번 더 확인해 쓸 계획입니다.
